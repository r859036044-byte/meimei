# 城市服務員物語（RPG Maker 風格原型）

世界觀：這座城市裡「持照服務員」是合法、受尊敬的正式職業。
女主角要在各區（辦公區／商業區／港口區／住宅區／公園）找到**需要被照顧的男性**，
先**徵得同意**，再選擇對症的服務，累積**績效評分**與**人氣**。
（內容為非露骨表現：服務過程以黑幕與時間流逝帶過。）

## 玩法
- 方向鍵 / WASD：移動　Z / Enter / 空白：決定、搭話　X / Esc：狀態　手機有螢幕按鍵
- 頭上有「！」的人就是需要幫助的人（紅＞橘＞黃＝需求越急，報酬越高）
- 搭話後，對方的台詞會透露需求：疲憊／孤單／壓力／低落
- 服務契合度：按摩治疲憊·壓力、傾聽治孤單、安慰治低落、約會適合孤單·壓力
- 評分 = 契合度 + 體力 + 需求急迫度 + 技巧等級；S/A/B/C 評級，影響收入與人氣
- 回自宅（住宅區）休息或睡覺；每天 08:00–24:00，共 7 天，最後依平均評價與人氣給稱號
